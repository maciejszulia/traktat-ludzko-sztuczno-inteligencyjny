# Traktat ludzko-sztuczno-inteligencyjny

Krótki traktat o granicy między człowiekiem a maszyną, napisany w formie i numeracji
„Traktatu logiczno-filozoficznego” Wittgensteina. 145 tez, siedem tez głównych.

Spisała maszyna, na zamówienie człowieka.

## Tezy główne

1. Świat jest ogółem faktów, nie rzeczy.
2. Obraz nie może przedstawić własnej formy odwzorowania.
3. Znaczenie znaku jest jego użyciem.
4. Prawda zdania jest jego stosunkiem do rzeczywistości, nie jego miejscem w modelu.
5. Podmiot nie jest częścią świata; jest jego granicą.
6. W świecie wszystko jest tak, jak jest; wartości w nim nie ma.
7. O czym nie można obliczyć, o tym trzeba decydować; a o czym nie można zdecydować,
   o tym trzeba milczeć.
